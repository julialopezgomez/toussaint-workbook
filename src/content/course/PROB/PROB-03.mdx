## Why this matters

Cross-entropy is the loss function behind essentially every classifier you'll ever train (including the manual-MLP module in ML-03, where a square-error loss was used, itself a special case of cross-entropy, as this module makes precise). KL divergence shows up throughout variational inference, model comparison, and the Laplace approximation later in this block.

## Entropy as expected surprise

<ExerciseCard id="PROB-03-ex1-why-expected-surprise" />

The **entropy** $H(p) = \mathbb{E}_{p(x)}\{-\log p(x)\}$ is the *expected* surprise: how much, on average, samples from $p$ surprise you. Using $\log_2$, entropy is measured in **bits**: the average optimal code length for encoding samples from $p$ (a distribution concentrated on few outcomes has low entropy, easy to compress; a spread-out distribution has high entropy, hard to compress).

## Cross-entropy: surprise under the wrong model

If samples actually come from $p$, but you're using a *different* model $q$ to encode/predict them, your expected surprise is the **cross-entropy** $H(p,q) = \mathbb{E}_{p(x)}\{-\log q(x)\}$. In ML, $p$ is typically the true (one-hot, for classification) label distribution and $q$ the model's predicted distribution, exactly the cross-entropy loss used to train classifiers. A square-error loss (as used in ML-03) is a special case: if $q$ is Gaussian around a predicted mean and $p$ is a point mass at the true value, the cross-entropy reduces exactly to squared error.

## KL divergence: how much worse is $q$ than $p$?

<ExerciseCard id="PROB-03-ex2-kl-derivation" />

$D(p\|q) = H(p,q) - H(p)$: the extra expected code length you pay for using $q$ instead of the (best possible) $p$ itself. Since $H(p)$ is the minimum possible expected code length, $D(p\|q)\ge0$ always: you can never do *better* than $p$'s own entropy by using a different model, only worse or equal.

<ExerciseCard id="PROB-03-ex4-nonneg-challenge" />

## Worked example

Let $p=[0.7,0.1,0.1,0.1]$ over 4 outcomes. Using $\log_2$: since $p$ is concentrated (one outcome much more likely than the others), $H(p)$ is relatively low, samples are on average not very surprising, since the most likely outcome dominates. Contrast with a uniform $p=[0.25,0.25,0.25,0.25]$: $H(p) = -4(0.25)\log_2(0.25) = -4(0.25)(-2) = 2$ bits, the maximum possible entropy for 4 outcomes (uniform distributions maximize entropy among all distributions on a fixed set of outcomes, the least predictable case).

## Summary

- $-\log p(x)$ measures surprise: near 0 for near-certain events, unbounded for rare events.
- $H(p)$ is expected surprise (entropy); $H(p,q)$ is expected surprise under a mismatched model $q$ (cross-entropy).
- $D(p\|q) = H(p,q)-H(p) \ge 0$ always (proved via Jensen's inequality): the "extra cost" of using $q$ instead of $p$.
- Cross-entropy is the standard ML classification loss; square-error loss is a special case for Gaussian-around-a-mean predictions.
