## Why this matters

PLAN-01 ended on the curse of dimensionality: exhaustive grid search over $Q_\text{free}$ doesn't scale past a handful of dimensions. **Probabilistic Roadmaps (PRM)** and **Rapidly-exploring Random Trees (RRT)** are the practical fix, and they're what actually gets used: instead of discretizing the whole space, sample randomly *within* $Q_\text{free}$ and build a graph/tree from those samples. Both are still standard tools in real motion-planning pipelines (including the kind directly relevant to TAMP).

## Probabilistic Roadmaps (PRM)

A PRM generates a graph $G=(V,E)$ of configurations such that every configuration along every edge lies in $Q_\text{free}$:

```
PRM-Generation(n samples, k nearest neighbors):
  Input:  number n of samples, number k of nearest neighbors
  Output: PRM graph G = (V, E)
  1: initialize V = ∅, E = ∅
  2: while |V| < n do
  3:     q ← random sample from Q
  4:     if q ∈ Q_free then V ← V ∪ {q}
  5: end while
  6: for all q ∈ V do
  7:     N_q ← k nearest neighbors of q in V
  8:     for all q' ∈ N_q do
  9:         if path(q, q') ∈ Q_free then E ← E ∪ {(q, q')}
  10:    end for
  11: end for
```
*(Marc Toussaint, `Lecture-Robotics.pdf`, p.70, §4.2:31.)*

`path(q, q')` is a **local planner**, most simply a straight line between the two configurations; since checking every point on that line is infeasible, the local planner instead tests collision at a finite resolution $\delta$ (a spacing parameter trading correctness against speed: too coarse a $\delta$ can miss a thin obstacle between checked points).

Once $G$ is built, finding a path from $q_\text{start}$ to $q_\text{goal}$ is just graph search (e.g. PLAN-01's Dijkstra) over $G$, which is why building the roadmap once and querying it many times is PRM's natural use case.

### Probabilistic completeness and narrow passages

For uniform sampling in a $d$-dimensional space, with $a,b\in Q_\text{free}$ connected by a path $\gamma$ of length $|\gamma|$ and **clearance** $\varrho$ (the minimum distance from $\gamma$ to any obstacle), the probability that a PRM finds a path after $n$ samples is bounded:

$$P(\text{PRM-success}\mid n) \geq 1-\frac{2|\gamma|}{\varrho}e^{-\sigma\varrho^dn}, \qquad \sigma=\frac{|B_1|}{2^d|Q_\text{free}|}$$

*(Kavraki, Švestka, Latombe & Overmars, 1995; stated as given in `Lecture-Robotics.pdf`, p.72, §4.2:34; $|B_1|$ is the volume of the unit ball in $d$ dimensions.)* This is called **probabilistic completeness**: the bound tends to $1$ as $n\to\infty$, so any target success probability is eventually achievable, but the required $n$ is exponential in $d$. Practically, the $1/\varrho$ and $\varrho^d$ factors mean this bound becomes vacuous (even negative, i.e. no guarantee at all) exactly when a passage is *narrow* (small $\varrho$): this is PRM's well-known **narrow passage problem**, uniform sampling is unlikely to ever land inside a thin gap.

<ExerciseCard id="PLAN-02-ex2-completeness-bound-numeric" />

A few refinements target this directly: **Gaussian sampling** (sample $q_1\sim\mathcal{U}$, $q_2\sim\mathcal{N}(q_1,\sigma)$; keep $q_1$ if exactly one of $q_1,q_2$ is in $Q_\text{free}$, biasing samples toward the boundary) and **bridge sampling** (sample $q_1,q_2$ similarly; if *both* are infeasible but their midpoint $q_3=(q_1+q_2)/2$ is feasible, keep $q_3$, directly targeting thin free-space corridors). Both trade the simplicity of uniform sampling for better narrow-passage coverage.

## Rapidly-exploring Random Trees (RRT)

RRTs address two different concerns: **single-query** efficiency (focus computation on one specific $(q_\text{start},q_\text{goal})$ pair rather than precomputing an exhaustive roadmap) and **control-based** exploration (incrementally growing using actually-controllable directions of motion, which extends naturally to differential constraints, PLAN-03's subject).

```
Simplest-RRT(q_start, n nodes, stepsize α):
  Input:  q_start, number n of nodes, stepsize α
  Output: tree T = (V, E)
  1: initialize V = {q_start}, E = ∅
  2: for i = 0 : n do
  3:     q_target ← random sample from Q
  4:     q_near ← nearest neighbor of q_target in V
  5:     q_new ← q_near + α/|q_target - q_near| · (q_target - q_near)
  6:     if q_new ∈ Q_free then V ← V ∪ {q_new}, E ← E ∪ {(q_near, q_new)}
  7: end for
```
*(Marc Toussaint, `Lecture-Robotics.pdf`, p.76, §4.2:39.)*

A **goal-biased** variant occasionally samples the goal itself directly, pulling the tree toward it rather than exploring purely at random:

```
Goal-biased-RRT(q_start, q_goal, n nodes, stepsize α, bias β):
  Input:  q_start, q_goal, number n of nodes, stepsize α, bias probability β
  Output: tree T = (V, E)
  1: initialize V = {q_start}, E = ∅
  2: for i = 0 : n do
  3:     if rand(0,1) < β then q_target ← q_goal
  4:     else q_target ← random sample from Q
  5:     q_near ← nearest neighbor of q_target in V
  6:     q_new ← q_near + α/|q_target - q_near| · (q_target - q_near)
  7:     if q_new ∈ Q_free then V ← V ∪ {q_new}, E ← E ∪ {(q_near, q_new)}
  8: end for
```
*(Marc Toussaint, `Lecture-Robotics.pdf`, p.77, §4.2:40.)*

**Bi-directional search** grows two trees simultaneously, one from $q_\text{start}$ and one from $q_\text{goal}$, letting each grow toward the other (e.g. using the newest node of tree 1 as the sample target for tree 2), typically finding a connection much faster than a single tree searching for a small goal region. **RRT\*** (Karaman & Frazzoli, 2010) extends the basic RRT with a rewiring step that asymptotically converges to the *optimal* path, not merely a feasible one, at the cost of extra bookkeeping per iteration.

## PRM vs. RRT

| | PRM | RRT |
|---|---|---|
| Best for | Multi-query (many start/goal pairs, one environment) | Single-query (one specific start/goal pair) |
| Precomputation | Exhaustive roadmap upfront (expensive, but amortized over queries) | None: builds only what's needed for this query |
| Differential constraints | Not naturally (assumes a usable local planner between *any* two samples) | Naturally extensible (PLAN-03) |
| Shared strengths | Algorithmically simple, highly explorative, probabilistic performance guarantees | Same |
| Shared caveats | Nearest-neighbor metric choice can be critical; local planner may be non-trivial | Same |

## Summary

- **PRM** builds a roadmap graph $G=(V,E)$ by sampling $n$ random configurations in $Q_\text{free}$ and connecting nearby pairs via a local planner (resolution-checked straight lines); once built, any query is a graph-search problem.
- PRM is **probabilistically complete**: success probability $\to1$ as $n\to\infty$, but the bound becomes vacuous for narrow passages (small clearance $\varrho$), motivating Gaussian/bridge sampling.
- **RRT** grows a single tree via nearest-neighbor-then-step-toward-a-random-sample, giving rapid, space-filling exploration without explicitly targeting uniform coverage; a goal-biased variant occasionally samples the goal directly.
- PRM suits multi-query problems (amortized precomputation); RRT suits single-query problems and extends naturally to differential constraints (PLAN-03).
