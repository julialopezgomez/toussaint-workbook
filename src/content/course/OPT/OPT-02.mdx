## Why this matters

Least-squares objectives are everywhere in robotics: trajectory optimization costs, sensor calibration, system identification, and the convex-decomposition manipulation planner from your own research are all, underneath, repeatedly solving least-squares-flavored subproblems. Gauss-Newton is the standard workhorse for exactly this reason: it gets most of Newton's fast convergence without needing the true, expensive Hessian. BFGS and conjugate gradient extend the same idea to problems that *don't* have least-squares structure.

## Gauss-Newton: exploiting least-squares structure

Consider a least-squares problem, cost as a sum-of-squares: $\min_xf(x)=\phi(x)^\top\phi(x)=\sum_{i=1}^d\phi_i(x)^2$, with features $\phi(x)\in\mathbb{R}^d$ and Jacobian $J=\frac{\partial}{\partial x}\phi(x)\in\mathbb{R}^{d\times n}$. The gradient and exact Hessian of $f$ are:

$$\nabla f(x) = 2\frac{\partial}{\partial x}\phi(x)^\top\phi(x) = 2J^\top\phi(x)$$

$$\nabla^2f(x) = 2\frac{\partial}{\partial x}\phi(x)^\top\frac{\partial}{\partial x}\phi(x) + 2\phi(x)^\top\nabla^2\phi(x) = 2J^\top J + 2\sum_i\phi_i(x)\nabla^2\phi_i(x)$$

**The Gauss-Newton method is exactly the Newton method for this $f$, while approximating the second term as zero**, i.e. $\nabla^2\phi(x)\approx 0$:

$$\nabla^2f(x) \approx 2J^\top J$$

<ExerciseCard id="OPT-02-ex2-gauss-newton-derivation" />

Two structural facts make this approximation especially good, not just cheap:

- **$J^\top J$ is always positive semi-definite** (for any real matrix $J$): it's a sum of rank-1 PSD terms, $J^\top J = \sum_i\nabla\phi_i(x)\nabla\phi_i(x)^\top$ (each $\nabla\phi_i\nabla\phi_i^\top$ PSD by [MATH-04](/course/MATH/MATH-04)'s covariance-matrix argument). So unlike the true Hessian, it can never be indefinite in a way that sends a naive Newton step in a wrong (ascending) direction, exactly the failure mode from [OPT-01](/course/OPT/OPT-01).
- **If the Jacobian $J$ is sparse, so is $J^\top J$**, giving useful graphical/factor-graph structure for large problems (bundle adjustment, SLAM, structured robotics path optimization).
- $J^\top J$ can be interpreted as the **pullback of the Euclidean norm in feature space**, $\phi^\top\phi$: since $\phi$ is $x$-dependent, this defines a **non-constant (Riemannian) metric** in $x$-space, exactly the "metric" idea from OPT-01's steepest-descent section and MATH-05's covariant gradient, but now the metric itself varies smoothly with $x$ rather than being fixed.

## Worked example

Let $\phi(x) = \begin{pmatrix}x_1-2\\x_2-3\\x_1+x_2-4\end{pmatrix}$ (linear, so $J$ is constant: $J=\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}$), starting at $x_0=\begin{pmatrix}0\\0\end{pmatrix}$. Then $\phi(x_0)=\begin{pmatrix}-2\\-3\\-4\end{pmatrix}$, $J^\top J = \begin{pmatrix}2&1\\1&2\end{pmatrix}$, $J^\top \phi(x_0) = \begin{pmatrix}-6\\-7\end{pmatrix}$, giving (the factor of 2 cancels between $\nabla f$ and $\nabla^2f$, so the step formula is exactly $\delta=-(J^\top J)^{-1}J^\top\phi(x_0)$):

$$\delta = -(J^\top J)^{-1}J^\top \phi(x_0) \approx \begin{pmatrix}1.667\\2.667\end{pmatrix}$$

*(Verified with NumPy against the true least-squares solution via `lstsq`: they match exactly, since Gauss-Newton is exact, not approximate, whenever $\phi(x)$ is linear.)*

## A robotics instance: discretized path optimization

Path optimization discretizes a trajectory $x=(x_1,..,x_T)$, $x_t\in\mathbb{R}^n$, and penalizes both smoothness (via a discrete acceleration-like term) and reaching a target configuration:

$$\min_x \sum_{t=1}^T\|x_t+x_{t-2}-2x_{t-1}\|^2 + \|\phi(x_T)\|^2$$

where $x_0,x_{-1}$ are given (boundary/start conditions) and $\phi(x_T)$ are features of the final configuration (e.g. end-effector position error). This is *exactly* the sum-of-squares form Gauss-Newton is built for: the smoothness terms are linear in $x$ (quadratic cost, Gauss-Newton exact there), while $\phi(x_T)$ may be a nonlinear function of the final configuration alone (e.g. forward kinematics), contributing the only place the Gauss-Newton approximation is actually approximate. This structure, and the sparsity of its Jacobian (each smoothness term only touches 3 consecutive time steps), is exactly what makes trajectory optimization tractable at scale, and is the same structural idea behind bundle adjustment and factor-graph SLAM.

## Quasi-Newton methods: BFGS

If you *cannot* evaluate $\nabla^2f(x)$ at all (no least-squares structure to exploit), can you still get 2nd-order behavior? Yes: approximate $\nabla^2f(x)$ from data $\{(x_i,\nabla f(x_i))\}$ collected along the optimization path. Given two gradient evaluations at $x_1,x_2$, with $y=\nabla f(x_2)-\nabla f(x_1)$ and $\delta=x_2-x_1$, what matrix $H$ (or $H^{-1}$) satisfies

$$H\delta \overset{!}{=} y \qquad\text{(the secant equation)}$$

The "simplest" symmetric rank-1-per-update solutions, updating an existing estimate $\hat H\approx H$ (or $\hat H^{-1}\approx H^{-1}$) with each new $(\delta,y)$ pair, are the **Broyden-Fletcher-Goldfarb-Shanno (BFGS)** update:

```
BFGS
Input:    initial x ∈ ℝⁿ, functions f(x), ∇f(x), tolerance θ
Output:   x
1: initialize Ĥ⁻¹ = Iₙ
2: repeat
3:   compute δ = -Ĥ⁻¹∇f(x)
4:   perform a line search  min_α f(x+αδ)
5:   δ ← αδ
6:   y ← ∇f(x+δ) - ∇f(x)
7:   x ← x + δ
8:   update Ĥ⁻¹ ← (I - δyᵀ/yᵀδ) Ĥ⁻¹ (I - yδᵀ/yᵀδ) + δδᵀ/yᵀδ
9: until ‖δ‖∞ < θ
```
*(Marc Toussaint, `lecture-optimization.pdf`, p.18. The two outer bracket terms "delete" old Ĥ⁻¹-components along δ; the trailing δδᵀ/yᵀδ term "inserts" the newly measured curvature. Equivalent to the Sherman-Morrison formula.)*

This update is a genuine rank-2 correction each step: it "deletes" old $\hat H^{-1}$-components along $\delta$ (the two outer bracket terms) and "inserts" the newly measured curvature $\delta\delta^\top/y^\top\delta$. In high dimensions, storing the dense $\hat H^{-1}$ is itself expensive; **L-BFGS** (limited-memory BFGS) instead stores only a handful of the most recent rank-1 update vectors and reconstructs $\hat H^{-1}$'s action on a vector on the fly, trading a little accuracy for $O(n)$ (not $O(n^2)$) memory. BFGS is, in practice, a default general-purpose solver across science and ML whenever gradients (but not Hessians) are available.

## Conjugate gradient

**Conjugate gradient (CG)** takes a different approach again: it never forms *any* explicit Hessian approximation, only ever using the gradient itself, and builds search directions that are mutually **conjugate** (non-interfering) under the true Hessian $H$: $\delta_i^\top H\delta_j=0$ for $i\ne j$. The motivating picture: after an exact line search to $x_2$ along direction $\delta_1$, the iso-lines of $f$ at $x_2$ are tangential to $\delta_1$; the *next* search direction should be "orthogonal" to $\delta_1$, but orthogonal w.r.t. the Hessian metric ($\delta_2^\top H\delta_1=0$), which is exactly what "conjugate" means.

```
Conjugate Gradient
Input:    initial x ∈ ℝⁿ, functions f(x), ∇f(x), tolerance θ
Output:   x
1: initialize descent direction δ = g = -∇f(x)
2: repeat
3:   α ← argmin_α f(x+αδ)                    // line search
4:   x ← x + αδ
5:   g' ← g,  g ← -∇f(x)                       // store and compute grad
6:   β ← max{ gᵀ(g-g') / g'ᵀg' , 0 }
7:   δ ← g + βδ                                // conjugate descent direction
8: until |Δx| < θ
```
*(Marc Toussaint, `lecture-optimization.pdf`, p.19. β > 0: the new descent direction always adds a bit of the old direction — this momentum essentially provides 2nd-order information. The β update is by Polak-Ribière.)*

The new direction $\delta\leftarrow g+\beta\delta$ always adds a bit of the *old* search direction, momentum that essentially provides 2nd-order information without ever computing $H$ explicitly. On a genuinely quadratic $f(x)=x^\top Ax+b^\top x$, the Polak-Ribière $\beta$ leads exactly to conjugate directions $\delta_i^\top A\delta_j=0$, and **CG converges in at most $n$ iterations** for such a quadratic (each new direction eliminates error along a new, non-interfering axis), though this requires an *exact* line search at each step, in practice usually approximated.

## Summary

- The exact Hessian costs $O(n^2)$ memory and $O(n^3)$ to solve with, impractical for large problems.
- For $f(x)=\phi(x)^\top\phi(x)$, $\nabla^2f(x) = 2J^\top J + 2\sum_i\phi_i\nabla^2\phi_i$; Gauss-Newton drops the second term. $J^\top J$ is always PSD, sparse when $J$ is sparse, and interpretable as a pullback (Riemannian) metric.
- The Gauss-Newton step formula $\delta=-(J^\top J)^{-1}J^\top\phi(x)$ is exact when $\phi$ is linear, and a good approximation near a good fit generally; discretized path/trajectory optimization is a direct instance of this structure.
- BFGS approximates the Hessian (or its inverse) from gradient history alone, via a rank-2 update satisfying the secant equation $\hat H\delta=y$; L-BFGS trades exactness for $O(n)$ memory.
- Conjugate gradient builds Hessian-conjugate search directions using only gradients, converging in at most $n$ steps on an exact quadratic with exact line search.
