## Why this matters

This module is ODE-02's linear-systems machinery, applied directly: PID control turns a control-design question ("how should the motor push?") into an ODE-classification question ("is the resulting characteristic equation's roots real or complex, positive or negative real part?"), which you already know how to answer. The 1D point mass is deliberately the simplest possible case, general robot dynamics (DYN-01's $M(q)\ddot q+F(q,\dot q)=u$) reduce to exactly this picture once linearized, which is why point-mass control is a genuine reference case, not a toy.

## The 1D point mass

The simplest possible dynamical system with inertia: no gravity, no friction, just a mass $m$ with state $x(t)=(q(t),\dot q(t))$ and dynamics $\ddot q(t)=u(t)/m$ (control $u$ is the applied force).

## Proportional feedback: "always pull toward the goal"

The simplest control law, $u=K_p(q^*-q)$ (pull toward goal $q^*$ with a force proportional to the error), turns the dynamics into a closed-loop ODE:

$$m\ddot q = K_p(q^*-q)$$

<ExerciseCard id="DYN-02-ex1-p-control-derivation" />

Solving via the ansatz $q(t)=a+be^{\omega t}$ (exactly ODE-02's eigenvalue ansatz, now for a 2nd-order scalar ODE) gives $\omega=\pm i\sqrt{K_p/m}$: **pure imaginary roots**, an undamped oscillation around $q^*$ at frequency $\sqrt{K_p/m}$ that never settles, exactly ODE-02's "center" classification. Proportional feedback alone never converges, it perpetually overshoots.

## Derivative feedback: "damp the system"

Add a term proportional to velocity error, $u=K_p(q^*-q)+K_d(\dot q^*-\dot q)$ (with $\dot q^*=0$ for simplicity, a fixed target):

$$m\ddot q = K_p(q^*-q)-K_d\dot q$$

<ExerciseCard id="DYN-02-ex2-pd-characteristic-equation" />

The same ansatz gives characteristic roots $\omega=\dfrac{-K_d\pm\sqrt{K_d^2-4mK_p}}{2m}$: **the exact quadratic-formula/discriminant structure from ODE-02's stability classification**, now with a name for each regime:

$$K_d^2<4mK_p \Rightarrow \text{oscillatory-damped (complex roots)}, \quad K_d^2>4mK_p\Rightarrow\text{over-damped (real roots)}, \quad K_d^2=4mK_p\Rightarrow\text{critically damped}$$

## An equivalent, more intuitive parameterization

Gains $(K_p,K_d)$ don't map intuitively onto "how fast" and "how oscillatory" a response looks. The standard fix: reparameterize by **time-scale** (wavelength) $\lambda=1/\sqrt{K_p/m}$ and **damping ratio** $\xi=K_d/\sqrt{4mK_p}$ (so $K_p=m/\lambda^2$, $K_d=2m\xi/\lambda$), giving

$$q(t) = q^*+be^{-\xi t/\lambda}e^{i\sqrt{1-\xi^2}\,t/\lambda}$$

with $\xi>1$ over-damped, $\xi=1$ critically damped, $\xi<1$ oscillatory-damped, exactly matching the discriminant classification above, now expressed as a single dimensionless number $\xi$ that means the same thing regardless of $m$ or the target time-scale $\lambda$.

## Integral feedback and PID

**Idea 3**: "pull if the position error has accumulated over time" (corrects for a constant disturbance a pure PD controller can't fully cancel, e.g. friction or a constant external load):

$$u = K_p(q^*-q)+K_d(\dot q^*-\dot q)+K_i\int_{s=0}^t(q^*(s)-q(s))\,ds$$

This isn't a linear ODE in $x=(q,\dot q)$ alone (the integral term depends on the whole history, not just the current state), but extending the state to $x=(q,\dot q,e)$ with $e(t)=\int_0^t(q^*-q)\,ds$ restores linearity: $\dot q=\dot q$, $\ddot q = u/m$, $\dot e = q^*-q$, an ODE system in the augmented state, exactly ODE-02's machinery again (now 3-dimensional), just with a third state variable tracking accumulated error.

## Summary

- The 1D point mass, $\ddot q=u/m$, is the reference dynamical system every general robot's linearized dynamics reduces to.
- P control alone gives a pure oscillation (ODE-02's "center"), never converging; PD control's characteristic equation $m\omega^2+K_d\omega+K_p=0$ classifies the response into oscillatory-damped/over-damped/critically-damped by the discriminant $K_d^2-4mK_p$, exactly ODE-02's stability machinery.
- The $(\lambda,\xi)$ reparameterization (time-scale, damping ratio) is a more intuitive, dimensionless way to specify the same gains.
- The integral term of PID isn't linear in $(q,\dot q)$ alone; augmenting the state with the accumulated error $e$ restores linearity, letting the same ODE toolbox apply.
