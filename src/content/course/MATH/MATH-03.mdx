## Why this matters

Nearly everything downstream in this course (rotation matrices, the SVD, PCA, even neural network weight matrices) is really a statement about linear maps between vector spaces, expressed in a chosen basis. Being sloppy about the vector/coordinate distinction is a common, quiet source of bugs when multiple coordinate frames are involved, exactly the situation you're in constantly in robotics (base frame, end-effector frame, world frame). This module makes that distinction precise.

## Vector spaces and bases, briefly

A **vector space** is a set of objects (vectors) closed under addition and scalar multiplication, satisfying the usual algebraic axioms (associativity, distributivity, etc.). A **basis** $\{b_1,\dots,b_n\}$ is a linearly independent set that spans the space: every vector $v$ can be written uniquely as $v = \sum_i c_i b_i$. The $c_i$ are $v$'s **coordinates** in that basis.

Crucially: $v$ itself doesn't depend on which basis you chose, but $[v]_B = (c_1,\dots,c_n)$ absolutely does.

## Change of basis

Given $v$'s coordinates in the standard basis (i.e. just $v$ itself, written as a list of numbers the usual way), how do you find its coordinates in a *different* basis $B$?

<ExerciseCard id="MATH-03-ex2-change-of-basis-derivation" />

## Worked example

Let $v = \begin{pmatrix}3\\2\end{pmatrix}$, and a new basis $b_1=\begin{pmatrix}1\\1\end{pmatrix}$, $b_2 = \begin{pmatrix}1\\-1\end{pmatrix}$, so $B = \begin{pmatrix}1&1\\1&-1\end{pmatrix}$.

$$\det(B) = 1(-1)-1(1) = -2, \qquad B^{-1} = \frac{1}{-2}\begin{pmatrix}-1&-1\\-1&1\end{pmatrix} = \begin{pmatrix}0.5&0.5\\0.5&-0.5\end{pmatrix}$$

$$[v]_B = B^{-1}v = \begin{pmatrix}0.5&0.5\\0.5&-0.5\end{pmatrix}\begin{pmatrix}3\\2\end{pmatrix} = \begin{pmatrix}2.5\\0.5\end{pmatrix}$$

*(Verified: $2.5\,b_1 + 0.5\,b_2 = 2.5\begin{pmatrix}1\\1\end{pmatrix}+0.5\begin{pmatrix}1\\-1\end{pmatrix} = \begin{pmatrix}2.5+0.5\\2.5-0.5\end{pmatrix} = \begin{pmatrix}3\\2\end{pmatrix} = v$. Matches.)*

## Matrices as linear maps

A matrix $A$ isn't fundamentally "a grid of numbers", it's the coordinate representation of a **linear map** (a function $T$ satisfying $T(u+v)=T(u)+T(v)$ and $T(\alpha v) = \alpha T(v)$) in a particular pair of bases (one for the input space, one for the output space). This is exactly why the *same* linear map can look like a very different matrix depending on your basis choice, and it's the conceptual foundation for why the SVD (next module) is interesting: it finds the basis pair in which a linear map's matrix representation is as simple as possible (diagonal).

## Summary

- A vector is basis-independent; its coordinates are not.
- Change of basis: $[v]_B = B^{-1}v$, where $B$'s columns are the new basis vectors.
- A matrix represents a linear map relative to chosen input/output bases, the same map can have very different matrix forms in different bases.
