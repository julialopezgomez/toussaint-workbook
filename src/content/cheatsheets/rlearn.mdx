## Definitions

- **Taxonomy** (RLEARN-00): every robot-learning method answers two independent questions — *what* is learned (dynamics/policy/reward/plan/value/state) and *how* is the data generated (demonstration/online/simulation/optimal/safe).
- **Dynamics learning** (RLEARN-01): fit a model $f_\Theta$ (parameter estimation, full regression, or residual-on-top-of-a-nominal-model) to observed transitions.
- **Imitation learning** (RLEARN-02): behavior cloning fits $\pi_\theta$ to expert actions directly; DAgger fixes the distributional-shift problem (errors compound at $O(T^2)$) by querying the expert on the learner's *own* visited states.
- **RL in robotics** (RLEARN-03): potential-based reward shaping changes the reward without changing the optimal policy; robots also need structured exploration noise (not i.i.d.) since physical actuators can't jitter instantaneously.
- **Offline RL & sim2real** (RLEARN-04): learning from a fixed dataset without further interaction; domain randomization trains across many simulated dynamics parameters so the learned policy is robust to the sim2real gap.
- **Inverse RL** (RLEARN-05): infer a reward function from expert behavior instead of assuming one is given; Adversarial IRL's discriminator decomposition is, algebraically, exactly RLEARN-03's reward-shaping formula, converging to the advantage function.
- **Grasp/manipulation learning** (RLEARN-06): grasp-quality labels generated by a privileged teacher (exact-pose force-closure computation, or simulation), then a sensor-based (RGB-D) student network learns to reproduce the judgment.
- **TAMP & LGPs** (RLEARN-07): task/motion/force abstraction levels; a Logic-Geometric Program jointly optimizes a discrete symbolic skeleton and a continuous trajectory subject to within-mode and mode-transition constraints.
- **Multi-robot learning** (RLEARN-08): Deep Sets/GNNs give permutation-invariant architectures for a variable number of neighbors; Markov games generalize a single-agent MDP to $N$ agents.

## Core equations

| Quantity | Formula | Module |
|---|---|---|
| Dynamics-learning objective | $\min_\Theta\sum_t\|x_t-f_\Theta(x_{t-1},u_{t-1})\|^2$ | RLEARN-01 |
| Behavior cloning objective | $\min_\theta\sum_{i,t}\ell(u_t^i,\pi_\theta(x_t^i))$ | RLEARN-02 |
| Reward shaping | $R'(s,a,s')=R(s,a,s')+\gamma\Phi(s')-\Phi(s)$ | RLEARN-03 |
| Domain randomization | $x_{t+1}=f(x_t,u_t;\Theta)$, $\Theta\sim p(\Theta)$ resampled per episode | RLEARN-04 |
| Linear-reward IRL objective | $J(\pi)=w^\top\mu(\pi)$, $\mu(\pi)=\mathbb E_\pi\{\sum_t\gamma^t\phi(s_t,a_t)\}$ | RLEARN-05 |
| AIRL discriminator | $f_{\theta,\phi}(s,a,s')=g_\theta(s,a)+\gamma h_\phi(s')-h_\phi(s)\to A(s,a)$ | RLEARN-05 |
| LGP objective | $\min_{s_{1:K},\bar x}\int c(\bar x(t))\,dt$ s.t. $\bar\phi\le0$ (within-mode), $\hat\phi\le0$ (mode-transition) | RLEARN-07 |
| Deep Sets aggregation | $f(X)\approx\rho\big(\sum_{x\in X}\phi(x)\big)$ | RLEARN-08 |

## Assumptions & applicability

- Behavior cloning's compounding-error bound is *quadratic* in horizon $T$; DAgger's on-policy correction is what tames this, at the cost of needing continued access to the expert during training, not just a fixed demonstration set.
- Reward shaping's guarantee (optimal policy unchanged) holds only for *potential-based* shaping specifically ($\Phi$ a function of state alone); arbitrary reward modifications can and usually do change the optimal policy.
- Domain randomization only helps if the true real-world dynamics parameter is actually inside (or near) the randomization distribution's support — randomizing over the wrong range doesn't transfer.
- The AIRL/reward-shaping connection (RLEARN-05) is an algebraic coincidence with real consequences: both use the exact same $g(s,a)+\gamma h(s')-h(s)$ form, which is why AIRL's discriminator converges to the advantage function under RL-04's Bellman equation.
- LGP's within-mode ($\bar\phi$) vs. mode-transition ($\hat\phi$) split is a computational one: $\bar\phi$ constrains an entire continuous interval (expensive), $\hat\phi$ only a single instant (cheap) — this is why TAMP methods spend most of their effort on the discrete skeleton search, not the continuous constraints.

## Common mistakes

- Using plain behavior cloning for a long-horizon task and being surprised by compounding drift — this is exactly the distributional-shift problem DAgger exists to fix.
- Forgetting reward shaping's guarantee requires $\Phi$ to depend only on state, not action — shaping based on $(s,a)$ pairs generally *does* change the optimal policy.
- Treating a grasp-quality network trained on privileged (simulation/exact-pose) labels as if it needs privileged input at deployment — the whole point of the privileged-teacher pattern (RLEARN-02/06) is that the deployed network only ever sees realistic sensor input.
- Conflating TAMP's task-level skeleton search with motion-level trajectory optimization — they're solved with different tools (discrete search vs. continuous optimization) precisely because they have different structure.

## Decision rule

- Have expert demonstrations but no reward function? Behavior cloning/DAgger (RLEARN-02) if the expert is queryable during training, inverse RL (RLEARN-05) if you specifically need the reward function itself (e.g. for downstream RL or interpretability).
- Training in simulation, need to deploy on real hardware? Domain randomization and/or the privileged-teacher pattern (RLEARN-04/06), depending on whether you need robustness to unknown dynamics or unknown sensing.
- Long-horizon manipulation with discrete structure (grasp/place/regrasp sequences)? TAMP/LGP (RLEARN-07) rather than trying to solve it as one flat continuous optimization or one flat MDP.
